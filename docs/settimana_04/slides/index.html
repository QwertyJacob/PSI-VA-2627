28′ · Le indicatrici

Una domanda diventa un bit

$I_A(\omega)=\begin{cases}1 & \omega\in A\\ 0 & \omega\notin A\end{cases}$
$P(I_A=1)=p\qquad P(I_A=0)=1-p$
$I_A\sim\operatorname{Bernoulli}(p)$
$$\mathbb{E}[I_A]=0\cdot(1-p)+1\cdot p=p=P(A)$$

contare in media = sommare probabilità

A = «la richiesta fallisce». Click: 1 l'interruttore scatta: 1 se A accade, 0 altrimenti; la definizione. Fai leggere 0 e 1 come valori, non come vero/falso. 2 la PMF: due sole barre, Bernoulli(p). «Successo» è una convenzione: qui un successo è un guasto. 3 la media del bit: il termine con 0 sparisce, resta p.
