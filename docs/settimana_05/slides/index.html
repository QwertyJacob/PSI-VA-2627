Prologo · Le unità

Euro al quadrato?

$\operatorname{Var}(B)=25\ \text{euro}^{\color{#ff6b6b}{2}}$

$$\sigma_X=\sqrt{\operatorname{Var}(X)}\qquad\sigma_B=\sqrt{25}=\color{#38ef7d}{5\ \text{euro}}$$
